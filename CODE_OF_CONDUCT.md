# Community conduct

Be respectful, constructive and welcoming. Discuss code and evidence, not personal attributes.
Harassment, threats, discrimination, private-data disclosure and repeated disruptive behavior
are unacceptable. Respect differing experience levels and maintainers' time.

Maintainers may edit/remove harmful content, limit participation or ban repeat offenders.
Report conduct problems privately through the owner's approved project contact once published.
A named enforcement contact is an owner approval gate before accepting public contributions.
Until then, this repository is an unpublished engineering workspace, not a supported community service.
